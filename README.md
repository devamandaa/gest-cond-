🏢 Gest-Cond – Gestão de Condomínios

Projeto em processo de criação, focado no desenvolvimento de uma plataforma para administração condominial.
A ideia é unir praticidade e tecnologia em um só sistema, ajudando síndicos, moradores e administradoras na gestão do dia a dia.

Atualmente, o projeto está em fase inicial e em constante evolução. 🚀
